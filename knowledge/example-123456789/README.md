# Project Knowledge Directory

This directory contains knowledge files for your project that Alfred will use to answer community questions.

## How to Use

1. Add your project's FAQ, documentation excerpts, or other knowledge in Markdown files
2. Reference them in your project config at `configs/projects/{guildId}.json`
3. Each file is truncated to 2000 characters when loaded into the AI prompt

## File Structure

- `faq.md` - Frequently asked questions and answers
- Add additional `.md` files as needed (e.g., `tokenomics.md`, `roadmap.md`)

## Best Practices

- Keep information concise and factual
- Update files when your project documentation changes
- Include links to official resources
- Focus on questions your community asks frequently
